# Supervisión continua

El proyecto se supervisa desde GitHub Actions.

## Qué revisar
- Estado de los workflows
- Logs de ejecución
- Resultados de pruebas
- Errores de build
- Reportes de seguridad

## Dónde verlo
En la pestaña **Actions** del repositorio.

## Qué hacer si falla
1. Abrir el job fallido.
2. Revisar los logs.
3. Identificar el paso que falló.
4. Corregir el archivo correspondiente.
5. Volver a ejecutar el workflow.
