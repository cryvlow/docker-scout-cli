# Mantenimiento del proyecto

## Actividades
- Revisión de workflows
- Actualización de acciones de GitHub
- Corrección de bugs
- Mejora del script de instalación
- Escaneo de vulnerabilidades
- Revisión periódica de dependencias

## Frecuencia
- Semanal: dependencias y acciones
- Por pull request: validación automática
- Mensual: revisión general del proyecto

## Objetivo
Mantener el proyecto estable, seguro y fácil de actualizar.
